# Target Pro

تطبيق ويب عربي لمتابعة الإنتاج اليومي والتارجت الشهري وتقدير المرتب.

## الملفات
- `index.html`: هيكل التطبيق.
- `styles.css`: التصميم المتجاوب والوضع الليلي/النهاري.
- `app.js`: الحسابات وحفظ البيانات والتفاعلات.
- `manifest.json`: إعدادات تثبيت التطبيق كتطبيق ويب.
- `service-worker.js`: التخزين المؤقت للعمل بعد أول تحميل.

## تشغيله من الهاتف
1. ارفع جميع الملفات إلى مستودع GitHub جديد باسم `Target-Pro`.
2. من المستودع افتح Settings ثم Pages.
3. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/root` واضغط Save.
4. انتظر ظهور رابط GitHub Pages وافتحه من Chrome على Android.
5. من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

## الإعدادات الافتراضية
- المرتب الأساسي: 5000 جنيه.
- أيام العمل الأساسية: 26.
- التارجت اليومي: 405 ملفات.
- قيمة اليوم: المرتب الأساسي ÷ 30.
- مكافأة العارضة غير المستخدمة: 3 × قيمة اليوم.
- الجمعة: مدفوعة، ويمكن اختيار إضافة تارجت 405 عن كل جمعة أو عدم إضافته.

## ملاحظات مهمة عن الحساب
- التارجت الشهري الافتراضي = (26 + عدد الجمعات إذا كان خيار الجمعة بتارجت كامل) × 405.
- عدد أيام العارضة غير المستخدمة يُدخل من شاشة المرتب. افتراضياً تخصم هذه الأيام 405 ملفات لكل يوم من التارجت، ويمكن تغيير ذلك من الإعدادات.
- مكافأة العارضة = عدد الأيام غير المستخدمة × معامل المكافأة × (المرتب الأساسي ÷ 30).
- الخصومات الإضافية لا تُحسب إلا إذا أدخلتها بنفسك.
- يوم الجمعة يُكتشف من تقويم الشهر المختار.
- البيانات تحفظ محلياً في متصفح الجهاز. لا تمسح بيانات المتصفح أو ملفات الموقع قبل تصدير نسخة احتياطية من التقارير.

## تنبيه
هذا إصدار ويب أولي قابل للتجربة، وليس APK أصلياً. GitHub Pages يتيح تشغيله كرابط ويب قابل للإضافة للشاشة الرئيسية. بناء APK أصلي يحتاج خطوة بناء Android منفصلة.


## تحديث الساعات الإضافية
- أضف عدد الساعات الإضافية لكل يوم من الرئيسية أو سجل الإنتاج.
- كل ساعة تضيف 60 ملفًا إلى تارجت ذلك اليوم تلقائيًا.
- يمكن تسجيل أكثر من ساعة وتعديلها أو حذفها مع سجل اليوم.
- التقرير الشهري يعرض إجمالي الساعات الإضافية وإجمالي الملفات المقابلة لها.
- النسخ الاحتياطي JSON يحفظ بيانات الساعات الإضافية أيضًا.

ملاحظة: تم الحفاظ على بيانات الإنتاج والإعدادات القديمة؛ بيانات الساعات تُحفظ في مفتاح محلي مستقل حتى لا تتأثر السجلات السابقة.
